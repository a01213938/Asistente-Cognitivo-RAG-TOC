# Asistente Cognitivo RAG - Innovación en la Gestión de Conocimiento

Este repositorio contiene el código, la documentación y los recursos para el desarrollo del **Asistente Cognitivo RAG**, un proyecto integrador desarrollado por el Equipo 11 del Tecnológico de Monterrey.

## 🏢 Contexto del Proyecto
* **Empresa / Institución:** Google Cloud (División Global Services Delivery - GSD)
* **Departamento:** Technical Onboarding Center
* **Sponsor:** Aaron Cardenas (Manager, Solutions Consultant)
* **Dominio de Aplicación:** IA Generativa

## 🎯 Objetivo y Justificación
El objetivo principal de esta solución es emplear una arquitectura de **Generación Aumentada por Recuperación (RAG)** utilizando modelos fundacionales multimodales de última generación (*Gemini Enterprise*). 

Se busca aprovechar la capacidad generativa del modelo para:
1. Sintetizar y crear respuestas contextuales precisas a partir del conocimiento institucional fragmentado.
2. Orquestar agentes autónomos.
3. Implementar la arquitectura avanzada "Antigravity RAG" (agentes autónomos auto-correctivos para razonamiento complejo).
